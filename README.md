# chatgpt-codex-test

HTML・CSS・JavaScriptだけで動くシンプルなToDoアプリです。外部ライブラリやビルドは不要です。

## ファイル構成

- `index.html`: 入力フォームとタスク一覧
- `style.css`: 画面のスタイル
- `app.js`: タスクの追加・完了切り替え・削除・保存

## 使い方

1. `index.html`、`style.css`、`app.js`を同じフォルダーに置き、`index.html`をブラウザーで開きます。
2. 入力欄にタスクを入力し、「追加」ボタンまたはEnterキーで追加します。空の入力や空白だけの入力は追加できません。
3. タスクのチェックボックスで完了／未完了を切り替えます。
4. 各タスクの「削除」ボタンで削除します。

タスクと完了状態は、ブラウザーの`localStorage`にキー`chatgpt-codex-test.todos.v1`で保存されます。同じブラウザー・同じURLで再読み込みすると復元されます。ブラウザーの保存データを消去するとタスクも消えます。

`file:` URLで開いた場合の保存動作はブラウザーによって異なります。安定して利用するにはHTTPの静的サーバーを推奨します。Pythonがある場合は、ファイルを置いたフォルダーで次を実行してください。

```sh
python -m http.server 8000
```

ブラウザーで <http://localhost:8000> を開いて使います。
